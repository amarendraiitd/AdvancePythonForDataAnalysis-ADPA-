# AdvancePythonForDataAnalysis-ADPA

Advance Python for Data Analysis is a foundation course before entering to the AI ML field.

This is a UG level course.

The course includes: 
  1. Intro to Python programming language
  2. Libraries for data analysis and Machine Learning: Numpy, Pandas, Matplotlib, Seaborn and Scikit-learn (sklearn)
  3. Statistics for data analysis
  4. Introduction to machine learning: Supervised (Regression, Classification) and Unsupervised (Clustering, PCA, etc.)
